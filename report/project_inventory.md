# IntelliClave Project Inventory and Run Guide

This document explains the function of each major folder and file in the IntelliClave project, then lists the main runnable files and what they show when executed.

## Run Assumptions

- Python commands are run from the project root after activating the IntelliClave conda environment.
- Frontend commands are run from dashboard/frontend/intelliclave-ui.
- Bash scripts can be run in Git Bash, WSL, or another shell that supports bash.
- Runtime files such as attestation.json, status.json, and results/* are generated by the project and should not be edited manually.

## Main Run Paths

If you want the shortest path to the most important outputs, these are the main entry points:

| Goal | Command | Output |
| --- | --- | --- |
| Validate processed data | python data/datascripts/check_data.py | Schema and data-quality report in the terminal |
| Rebuild class weights | python data/datascripts/weights.py | Updated data/class_weights.json |
| Run local training | python fl/train_local.py --csv data/processed/client1.csv --epochs 20 | Local accuracy and loss metrics |
| Run FL simulation | python fl/run_fl_simulation.py | FL round metrics and saved checkpoints |
| Run distributed FL | python fl/run_server.py and python fl/run_client.py --id 1/2/3 | Server and client training logs |
| Evaluate the final model | python fl/evaluate_global_model.py | Per-client final metrics in JSON |
| Run privacy sweep | python privacy/epsilon_sweep.py | DP tradeoff JSON files and plots |
| Run dashboard tests | python dashboard/backend/test_e2e.py | Endpoint pass/fail results |
| Build the final figure | python evaluation/generate_graph6.py | results/graphs/graph6_final_results.png |
| Run attack studies | python security/attacks/model_inversion.py, python security/attacks/membership_inference.py, python security/attacks/gradient_poisoning.py | Attack metrics and result JSON files |
| Run TEE demos | python tee/attestation/attestation_integration.py and python tee/sealed_storage/sealed_storage.py | Attestation and sealed-storage verification output |
